# Le marché de Nounou

Application web de caisse de dînette pour enfant — tablette Apple (paysage).

👉 **Application :** [`le-marche-de-nounou/`](le-marche-de-nounou/)

Documentation complète, démarrage, catalogue et tests : voir [`le-marche-de-nounou/README.md`](le-marche-de-nounou/README.md).

## Démarrage rapide

```bash
cd le-marche-de-nounou
python3 -m http.server 8080
```

Ouvrir `http://localhost:8080` (ou l’IP locale depuis l’iPad).

## Stack

- HTML / CSS / JavaScript vanilla
- Aucun framework, aucune dépendance npm, aucun CDN
- Prêt pour GitHub Pages et, plus tard, hébergement statique (ESP32, Raspberry Pi, etc.)
